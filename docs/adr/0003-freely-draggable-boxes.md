# Boxes are freely draggable to any position, not laid out by flow/grid or canonical order

Boxes are not arranged by document flow (list or wrapping grid), and there is no canonical/fixed ordering of syllables anywhere on the page — unlike the many existing pinyin web tools that just display a grid of all syllables in some fixed order. The learner can drag each box to any position in the browser window at any time and rearrange them freely, matching the existing Perl/Tk prototype's placement model. This matters because the app is designed to put the learner in charge of organizing their own learning space (e.g. keeping "zhí" and "jí" adjacent to bounce between them) rather than imposing an order the tool's author chose — the learner shouldn't be penalized for whatever order they happened to create boxes in. A simpler flex/grid layout was the obvious web-native default and was rejected for this reason, even though free positioning costs more implementation work (drag handling, coordinate tracking, overlap/z-index).
