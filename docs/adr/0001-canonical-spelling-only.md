# Never display or accept non-canonical pinyin spellings

This tutorial's teaching goal is that a learner should never see or type a form that isn't a legitimate step toward a valid pinyin syllable — e.g. the syllable "i" is never taught, only "yi"; ü is only ever produced by typing the canonical "u:" digraph, never the common "v" shortcut. We chose this over the more common approach (teach naked finals and shortcut substitutions, then explain the spelling-rule exceptions afterward) because presenting exceptions after the fact is exactly the confusion this app exists to prevent. In practice: keystrokes with an unambiguous canonical correction (like "u:" → "ü") auto-correct live in the entry box; keystrokes only judgeable at the whole-syllable level (like a lone "i") are instead caught by the validity engine's hint at submission time, not blocked live.
